# Построение бинарного дерева: рекурсия vs цикл 

Сравнение времени работы **рекурсивной** и **итеративной** (цикл + очередь)
реализаций построения бинарного дерева. Замеры выполняются модулем `timeit`,
результаты визуализируются графиком `matplotlib` — в обычной
и логарифмической шкале.

![График результатов](tree_benchmark.png)

##  Вариант задания (№1)

| Параметр | Значение |
|---|---|
| Корень (`root`) | **1** |
| Высота (`height`) | **5** |
| Левый потомок | `root * 2` |
| Правый потомок | `root + 3` |

Формулы потомков **параметризованы** — задаются лямбда-функциями
как аргументы по умолчанию:

```python
def build_tree_recursive(height=5, root=1,
                         left_branch=lambda r: r * 2,
                         right_branch=lambda r: r + 3):
    ...
```

##  Две реализации

| Функция | Подход | Структура данных | Расход стека |
|---|---|---|---|
| `build_tree_recursive` | рекурсия | стек вызовов Python | O(height) |
| `build_tree_iterative` | цикл (BFS) | `collections.deque` | O(1)* |

\* очередь узлов живёт в куче, а не на стеке вызовов.

Обе функции строят **идентичное дерево** в виде словаря:

```python
{'value': 1,
 'left':  {'value': 2, 'left': {...}, 'right': {...}},
 'right': {'value': 4, 'left': {...}, 'right': {...}}}
```

**Рекурсивный алгоритм:** узел = `{значение, левое поддерево, правое
поддерево}`, где поддеревья строятся той же функцией с `height − 1`.
База рекурсии — `height <= 0 → None`.

**Итеративный алгоритм:** очередь необработанных узлов (`deque`).
Достаём узел → создаём двух потомков → кладём их в очередь.
Дерево заполняется по уровням (обход в ширину). `popleft()` работает
за O(1) — поэтому именно `deque`, а не `list.pop(0)`.

Идентичность результатов проверяется автоматически (`check_equal()`)
для высот от 1 до 7 прямым сравнением словарей.

## 🔬 Методика измерений

1. **Один фиксированный список высот** для обеих функций:
   `HEIGHTS = [4, 6, 8, 10, 12, 14, 16]` (ось X графика).
2. **Многократные прогоны**: `timeit.repeat` — `REPEAT = 5` прогонов
   по `NUMBER = 3` построения дерева.
3. **Чистый бенчмарк одного построения**: берётся минимум из прогонов
   (наименее искажённый помехами ОС) и нормируется на `NUMBER`.
   Результат — время одного построения в **миллисекундах**.

##  Запуск

```bash
git clone https://github.com/<ваш-логин>/tree-build-benchmark.git
cd tree-build-benchmark
pip install -r requirements.txt
python tree_benchmark.py
```

При запуске последовательно выполняются:
1. проверка идентичности деревьев (рекурсия == цикл);
2. демонстрация дерева и параметризации своими формулами;
3. бенчмарк + таблица в консоли;
4. график → файл `tree_benchmark.png` (видно в Replit);
5. эксперимент с лимитом рекурсии;

##  Граница рекурсии (эксперимент)

В скрипте лимит рекурсии искусственно занижается до 100, после чего
строится дерево высотой 200:

```
  рекурсия: RecursionError - стек переполнен!
  цикл    : построил дерево height=20, узлов = 1048575
```

Рекурсивная версия падает — глубина рекурсии равна высоте дерева.
Итеративная версия ограничена только объёмом ОЗУ.

##  Выводы

- **Сложность обоих алгоритмов O(2^height)** — по числу узлов полного
  дерева. На логарифмической шкале обе линии становятся почти прямыми:
  время удваивается на каждый уровень высоты.
- **Итеративная версия быстрее в ~1.2–1.3 раза**: рекурсия несёт
  накладные расходы на каждый узел — отдельный вызов функции
  (кадр стека, передача 4 аргументов, возврат значения).
- **Рекурсия расходует стек вызовов** (глубина = height) и падает
  с `RecursionError` при большой высоте или заниженном лимите.
  Цикл хранит очередь в куче и ограничен только памятью.
- **Итог:** результат одинаковый, но итеративная версия быстрее
  и надёжнее. Рекурсивная — короче и нагляднее, подходит для
  небольших деревьев.

##  Ограничения

- Полное дерево содержит 2^height − 1 узлов — память растёт
  экспоненциально; высоты > 20 могут не поместиться в ОЗУ.
- Функции не валидируют вход — осознанное упрощение для бенчмарка.
- Абсолютные времена зависят от машины и версии Python;
  воспроизводимы только относительные соотношения.
